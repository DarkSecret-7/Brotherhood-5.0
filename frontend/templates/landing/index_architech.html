A working application, not a concept.

The Brotherhood platform is publicly accessible and actively developed. These are the features available now.

Core

Knowledge Graph Editor

Build structured graphs of skills, topics, and prerequisites. Version-controlled and collaboratively editable. Branching, merging, and forking all supported.

Multi-Author Workspaces

Invite collaborators to co-edit graphs. Proposal and consent system ensures democratic control — no unilateral changes to shared work.

AI Integration

LLM-Assisted Node Suggestions

Optional AI-powered suggestions via OpenRouter. Multiple model support including Qwen, DeepSeek, and Gemini. Fully opt-in — no data sent without your selection.

About This Project

The software is built on a larger idea.

The Brotherhood is part of a longer project: building open infrastructure for how people learn, prove capability, and coordinate work — without credential gatekeepers, institutional lock-in, or platform extraction.

The skill graph platform is the first concrete piece of that infrastructure. Every graph contributed, every pathway mapped, and every assessment recorded is part of building a shared, open memory for human knowledge.

The problem we're solving → Our response → System components → How to contribute →

Open Knowledge

All graphs, materials, and research are released under copyleft licenses. No paywalls, no gatekeeping, no proprietary lock-in.

Work-Based Assessment

Capability verified through observed collaboration — not credentials, not exams. Portable and auditable by design.

Federated Governance

Workers govern the systems they contribute to. Contribution weight, not ownership, determines decision-making power.

Forkable by Default

Every component — protocol, software, graphs — can be forked. No actor can lock in control permanently.
